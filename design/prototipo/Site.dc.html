Como instalar

  1. Baixe a ISO da versão certa para o seu computador.
  2. Grave a ISO num pendrive de 8 GB ou mais com o Fedora Media Writer. Tudo que estiver no pendrive será apagado.
  3. Reinicie o computador e escolha o pendrive no menu de boot.
  4. Siga o instalador. Ele mostra o que vai acontecer com o disco antes de gravar qualquer coisa.

Já usa Fedora Atomic?

Dá para trocar para o Draconic sem reinstalar. O sistema anterior continua no menu de boot até a próxima atualização.
